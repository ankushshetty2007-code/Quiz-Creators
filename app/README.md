# Next.js Project

This is a [Next.js](https://nextjs.org/) project created using `create-next-app`.

## Getting Started

First, install the dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to see the application.

## Project Structure

```text
my-app/
├── app/
│   ├── page.js
│   ├── layout.js
│   └── globals.css
├── public/
├── package.json
├── package-lock.json
└── README.md
```

## Development

- `app/page.js` – Main homepage of the application.
- `app/layout.js` – Root layout of the application.
- `app/globals.css` – Global styling.
- `public/` – Stores static assets such as images and icons.

You can start editing the page by modifying `app/page.js`. The page automatically updates as you make changes.
